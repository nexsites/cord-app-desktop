# Changelog

## [1.0.0] — 2026-09-08

Initial Cord Desktop release. Forked from
[stoatchat/for-desktop](https://github.com/stoatchat/for-desktop)
(itself descended from revoltchat/desktop) and rebranded top-to-bottom.

- Points at https://cord-app.com
- Windows only (Squirrel installer + portable ZIP)
- Auto-updates from GitHub releases via `update-electron-app`
- Discord Rich Presence disabled until a Cord Discord application id is registered
- Dropped: Linux Flatpak maker, macOS App Store maker, Nix + Mac-specific hooks
